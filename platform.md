<ul class="db-grid">
  <li class="db-card db-card--feature">
    <div class="db-card-top">
      <span class="db-index">01</span>
      <span class="db-kind">Deep ocean · 2026</span>
    </div>
    <h2 class="db-card-name">
      <a href="https://DeepOceanOmics.org">DOO</a>
    </h2>
    <p class="db-full">Deep Ocean Omics</p>
    <p class="db-desc">
      A centralised multi-omics atlas for deep-ocean organisms: 68 species
      across seven phyla, 72 genomes, 950 bulk transcriptomes, 15 single-cell
      transcriptomes and 1,112 metagenomes, with comparative and functional
      analysis toolkits built in.
    </p>
    <div class="db-links">
      <a href="https://DeepOceanOmics.org">Visit DOO ↗</a>
      <a href="https://doi.org/10.1093/nar/gkaf1096">Paper</a>
    </div>
  </li>

  <li class="db-card">
    <div class="db-card-top">
      <span class="db-index">02</span>
      <span class="db-kind">Cnidarian · 2026</span>
    </div>
    <h2 class="db-card-name">
      <a href="https://cnidosite.org">CnidoSite</a>
    </h2>
    <p class="db-full">Cnidarian multi-omics database</p>
    <p class="db-desc">
      Genomic and transcriptomic data for corals, sea anemones and jellyfishes,
      brought into a single comparative framework.
    </p>
    <div class="db-links">
      <a href="https://cnidosite.org">Visit CnidoSite ↗</a>
      <a href="https://doi.org/10.64898/2026.10.15.758670">Preprint</a>
    </div>
  </li>

  <li class="db-card">
    <div class="db-card-top">
      <span class="db-index">03</span>
      <span class="db-kind">Tomato · 2024</span>
    </div>
    <h2 class="db-card-name">
      <a href="https://bioinformatics.cau.edu.cn/TomAP/">TomAP</a>
    </h2>
    <p class="db-full">Tomato multi-omics analysis platform</p>
    <p class="db-desc">
      Co-expression networks integrated with defined chromatin states, so that
      co-expressed genes can be read together with their chromatin context and
      compared with orthologues across species.
    </p>
    <div class="db-links">
      <a href="https://bioinformatics.cau.edu.cn/TomAP/">Visit TomAP ↗</a>
      <a href="https://doi.org/10.1016/j.ncrops.2023.10.001">Paper</a>
    </div>
  </li>
