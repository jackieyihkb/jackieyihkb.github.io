---
title: Databases
lead: >-
  Multi-omics resources I have built or maintain. Each is designed around a
  biological question, not a file format.
---

<ul class="db-list">
  <li class="db-item">
    <div class="db-name">
      <a href="https://DeepOceanOmics.org">DOO</a>
      <span class="db-kind">Deep ocean · 2026</span>
    </div>
    <div class="db-body">
      <p>
        A centralised multi-omics atlas for deep-ocean organisms: 68 species
        across seven phyla, 72 genomes, 950 bulk transcriptomes, 15 single-cell
        transcriptomes and 1,112 metagenomes, with comparative and functional
        analysis toolkits.
      </p>
      <div class="db-links">
        <a href="https://DeepOceanOmics.org">Visit DOO ↗</a>
        <a href="https://doi.org/10.1093/nar/gkaf1096">Paper</a>
      </div>
    </div>
  </li>

  <li class="db-item">
    <div class="db-name">
      <a href="https://cnidosite.org">CnidoSite</a>
      <span class="db-kind">Cnidarian · 2026</span>
    </div>
    <div class="db-body">
      <p>
        A multi-omics database for cnidarians, the lineage that includes corals,
        sea anemones and jellyfishes. CnidoSite brings genomic and transcriptomic
        data from this group into a single comparative framework.
      </p>
      <div class="db-links">
        <a href="https://cnidosite.org">Visit CnidoSite ↗</a>
        <a href="https://doi.org/10.64898/2026.10.15.758670">Preprint</a>
      </div>
    </div>
  </li>

  <li class="db-item">
    <div class="db-name">
      <a href="https://bioinformatics.cau.edu.cn/TomAP/">TomAP</a>
      <span class="db-kind">Tomato · 2024</span>
    </div>
    <div class="db-body">
      <p>
        A multi-omics analysis platform for tomato. TomAP integrates
        co-expression networks with defined chromatin states, so that
        co-expressed genes can be examined together with their chromatin context
        and compared with orthologues across species.
      </p>
      <div class="db-links">
        <a href="https://bioinformatics.cau.edu.cn/TomAP/">Visit TomAP ↗</a>
        <a href="https://doi.org/10.1016/j.ncrops.2023.10.001">Paper</a>
      </div>
    </div>
  </li>

  <li class="db-item">
    <div class="db-name">
      <a href="https://bioinformatics.cau.edu.cn/HpeNet/">HpeNet</a>
      <span class="db-kind">Peony · 2020</span>
    </div>
    <div class="db-body">
      <p>
        A co-expression network database for <em>Paeonia lactiflora</em>, built
        from 40 in-house RNA-seq datasets across 10 tissues and a <em>de novo</em>
        transcriptome assembly, with BLAST, expression profiling and GSEA tools.
      </p>
      <div class="db-links">
        <a href="https://bioinformatics.cau.edu.cn/HpeNet/">Visit HpeNet ↗</a>
        <a href="https://doi.org/10.3389/fgene.2020.570138">Paper</a>
      </div>
    </div>
  </li>

  <li class="db-item">
    <div class="db-name">
      <a href="http://bioinformatics.cau.edu.cn/croFGD/">croFGD</a>
      <span class="db-kind">C. roseus · 2019</span>
    </div>
    <div class="db-body">
      <p>
        A functional genomics database for <em>Catharanthus roseus</em>, the
        source of monoterpene indole alkaloids. It combines a co-expression
        network with network search, comparison and analysis, gene-family, KEGG,
        GO and miRNA annotation.
      </p>
      <div class="db-links">
        <a href="http://bioinformatics.cau.edu.cn/croFGD/">Visit croFGD ↗</a>
        <a href="https://doi.org/10.3389/fgene.2019.00238">Paper</a>
      </div>
    </div>
  </li>

  <li class="db-item">
    <div class="db-name">
      <a href="http://structuralbiology.cau.edu.cn/PNRD/">PNRD</a>
      <span class="db-kind">Plant ncRNA · 2014–</span>
    </div>
    <div class="db-body">
      <p>
        The plant non-coding RNA database. During my PhD I contributed to its
        maintenance and upgrade: 924,127 entries of 14 ncRNA types from 221
        species, miRNA targets extended to 900,771 pairs in 57 species, and 142
        miRNA expression profiles across 47 species.
      </p>
      <div class="db-links">
        <a href="http://structuralbiology.cau.edu.cn/PNRD/">Visit PNRD ↗</a>
        <a href="https://doi.org/10.1093/nar/gku1162">Paper</a>
      </div>
    </div>
  </li>
</ul>
